# قيود أذونات المخزون

تطبيق مستقل لـ Odoo 17 يظهر في شاشة التطبيقات باسم **قيود أذونات المخزون**، ويضيف تبويبًا عربيًا باسم **القيود المحاسبية** إلى أذونات الاستلام والتسليم والتحويل.

## نطاق الربط

- قيود التقييم المرتبطة بحركات الإذن وطبقات التقييم التابعة لها، بما فيها الطبقات الفرعية الناتجة عن إعادة التقييم أو التكاليف الإضافية.
- فواتير العملاء وإشعاراتهم الدائنة المرتبطة فعليًا بخطوط البيع الموجودة في حركات الإذن.
- فواتير الموردين وإشعاراتهم الدائنة المرتبطة فعليًا بخطوط الشراء الموجودة في حركات الإذن.
- إزالة التكرار وتصنيف مصدر القيد، مع إظهار المسودة والمرحّل واستبعاد المستندات الملغاة والمدفوعات غير المرتبطة.

## الأمان

- لا يظهر التبويب إلا للمخولين بقراءة القيود المحاسبية عبر مجموعة `account.group_account_readonly` أو المجموعات الأعلى التي تتضمنها.
- لا يستخدم التطبيق `sudo` عند جلب القيود، ولذلك تبقى صلاحيات المحاسبة وقواعد عزل الشركات مطبقة.
- لا يعتمد الربط على المرجع النصي؛ بل على العلاقات النظامية بين الإذن والحركة وطبقة التقييم وخط البيع أو الشراء.

بعد نشر الكود يجب تحديث قائمة التطبيقات، ثم تثبيت **قيود أذونات المخزون** أو ترقيته إذا كان مثبتًا.
