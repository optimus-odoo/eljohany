# سجل تغييرات المنتجات

يسجل الموديول كل حقل يتغير فعليًا في قالب المنتج أو متغير المنتج، مع:

- المستخدم الذي نفّذ التعديل وتاريخه.
- اسم الحقل ووصفه.
- القيمة السابقة والقيمة الجديدة.
- مرجع موحد لحقول عملية الحفظ الواحدة.

## الصلاحية

بعد تثبيت الموديول، امنح المستخدم مجموعة **عرض سجل تغييرات المنتجات** من شاشة
المستخدمين. يظهر عندها تب **سجل التغييرات** داخل شاشة المنتج، بينما لا يملك
المستخدم صلاحية إنشاء سجلات التدقيق أو تعديلها أو حذفها.

تطبق قواعد الشركات المتعددة على السجل. يبدأ التسجيل من لحظة تثبيت الموديول،
ولا ينشئ تاريخًا رجعيًا للتعديلات السابقة.
