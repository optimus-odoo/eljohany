Open HRMS Loan Management
===========================
Eljohany compatibility policy
------------------------------
This is the active loan module on the Eljohany database and it uses
``hr_payroll_community``. Keep it with ``ohrms_loan_accounting`` and do not
install the local ``hr_loan`` alternative, because that alternative loads the
incompatible official ``hr_payroll`` engine. See
``docs/ohrms_loan_replacement.md`` for the compatibility and migration policy.

This module facilitates the creation and management of employee loan requests.

Configuration
=============
No additional configuration required
