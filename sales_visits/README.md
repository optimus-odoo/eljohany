About
============
Do you want to get the location of the partner(vendor, supplier, customer, client & contact) while check in & check out? You can get check in & check out geolocation of the partner. This module helps to track the real-location of employee visits at the partner place. You can select a partner while check in & visit type while check out. When partners check in & check out they can write messages, comments, or any notes. You can get geolocation result based on a filter like job position, date, department & employee name. So be very quick in all procedures and cheers!

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.
