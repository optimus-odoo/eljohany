Sales Visits With Location Tracking

Overview

odoo app to provide sales persons managing their visits for customers and storing it's details.
Sales visits Manager can configure the maximum allowed distance between the employee and the customer in Miles.
If employee in the allowed range then it stored in the visit as compliant else not compliant.
also Sales manager can add Visit Types to be used in visits later
Salesman can open clients map view to see his customers in the map and choose any customer to create visit by clicking on it in the map and then a popup will appear with details of the customer. and checkin visit button.
then if salesman open visits menu then he can see all visits of the customer.
If salesman click on the visit then he can see details of the visit and can set type of the visit and add description.
from map view of visits or customers he can check out visit.

Feature

Visits for customers.
Configure allowed distance between employee and customer.
Get employee current location when checkin and checkout of visit
Set allowed distance between employee current location and the location set for employee.
Calculation based on the settings to set if employee is inside location or outside.
Record all this information in visits record

How To Work

Client Visits menu
Set Groups for user (manager hav full access) or (user can create visits and see only his visits)
Set salesman for every customer
Set location for customers to be appeared in map
Sales visit settings for set max distance allowed between customer and employee
Configure Visit Type
Open sales vist menu and choose a customer from your customers
left click on the client and click on check in/out button to crate visit
navigate to visits menu to see your visits details
Open your visit to add it's type and add any notes
in visit details if you click on In URl or Out URL it will open salesman location in google maps
You can choose map view in visits to see the visit in map and you can select any opened visit to check it out
Visit when checked out will be closed automatically and you can select any visit to open it and add any notes
Visits can be filtered by status and date
