# كشف حساب الموردين الشامل

معالج محاسبي لنظام Odoo 17 يتيح اختيار مورد محدد أو جميع الموردين. يشمل التقرير
بنود القيود المرحلة من جميع الحسابات المرتبطة بالمورد، والرصيد الافتتاحي قبل
الفترة المحددة، وإجمالي المدين والدائن، والرصيد المتحرك، والرصيد الختامي. تعتمد
مخرجات PDF وExcel على مصدر بيانات موحد.

يوفر المعالج زر «عرض التقرير» لمعاينة التقرير مباشرة داخل المتصفح قبل تنزيله،
مع إبقاء تنزيل PDF وتصدير Excel كخيارين مستقلين.

يحتوي «خيار عرض التقرير» على عرض تفصيلي للقيود وعرض ملخص يكتفي بالرصيد
الافتتاحي وإجمالي حركة الفترة والرصيد الختامي. يستخدم العرض الملخص التجميع
المباشر لتحسين الأداء.

تعتمد تصفية الفترة على تاريخ القيد المحاسبي، ويظهر تاريخ الفاتورة أو المستند في
عمود مستقل حتى تظل المستندات المؤرخة بتاريخ سابق قابلة للمراجعة والتدقيق.
