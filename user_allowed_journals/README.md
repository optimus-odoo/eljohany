User Allowed Journals
=====================

What it does
------------
Adds a field on Users: 'Allowed Journals'.
If configured, the Payment Register wizard (account.payment.register) will only show journals that are:
- allowed by Odoo's standard logic (batches filters), AND
- included in the current user's Allowed Journals list.

Compatible with
---------------
Odoo 17.0

Notes
-----
- Leaving Allowed Journals empty keeps default behavior.
