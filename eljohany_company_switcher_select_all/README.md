# Company Switcher Select All

إضافة مستقلة لـ Odoo 17 تضيف أمرًا ثابتًا أعلى قائمة مبدّل الشركات:

- **اختيار الكل:** يفعّل جميع الشركات الموجودة في `allowedCompanies` للمستخدم الحالي في عملية واحدة.
- **إلغاء تحديد الكل:** يعيد النطاق إلى الشركة الحالية فقط، لأن Odoo يتطلب بقاء شركة نشطة واحدة على الأقل.
- يحافظ على الشركة الحالية كأول شركة في النطاق حتى لا تتغير الشركة الرئيسية للمستخدم عند اختيار الجميع.
- لا يستخدم `sudo` ولا يجلب شركات إضافية من الخادم؛ لذلك لا يمكنه تجاوز الشركات المسموح بها في جلسة المستخدم.
- يبقى الأمر ظاهرًا أعلى القائمة أثناء التمرير، ويعرض عدد الشركات التي سيشملها الاختيار.

بعد تثبيت الإضافة يجب إعادة بناء أصول الواجهة وتحديث الصفحة تحديثًا كاملاً.
