Product Sales by Location

Key Features:

  • Allows users to set a location on sale order line.
  • Whatever location is selected on sale order lines, the product will be delivered from the selected location.
  • Delivery orders will be created based on selected location on sale order lines.

Overview

  • On sales order lines, user have option for select location to deliver the product from selected location.
  • When sale order confirmed, the delivery orders will be created based on selected location.
  • As shown delivery order in below image, the product and source location as selected on sale order lines.
  • Another delivery order with the selected location and product.
  • User can also see the location on sales report.
  • In Customer portal, user can also see the location.
