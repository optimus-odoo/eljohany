# تقرير حركة المخزون بين فترتين (Odoo 17) + Excel

المسار: المخزون → التقارير → تقارير المخزون → حركة المخزون بين فترتين

## المميزات
- اختيار فترة (من/إلى)
- فلترة حسب المستودع أو اختيار مواقع متعددة
- فلترة حسب الأصناف أو الفئة
- الرصيد الافتتاحي
- 3 أوضاع:
  - تفاصيل الحركات
  - ملخص حسب الصنف
  - ملخص حسب الصنف والموقع
- تصدير Excel

## تسميات خاصة بالشركة
الإعدادات: الإعدادات → عام → (تقارير المخزون) → تسميات خاصة بالشركة - تقرير حركة المخزون
