# Extended Executive Intelligence

Adds verified providers for the executive, finance, sales, product, forecast,
human-resources, operations and risk dashboards. Every KPI is calculated from
Odoo records visible to the current user; unavailable or insufficient data is
reported explicitly instead of being replaced by estimates.

The providers now return verified visual datasets for financial ratios, sales
trends, customer order volume, product movement, department headcount,
manufacturing status, forecast coverage, shortage heatmaps, and risk severity.
The sales geographic distribution is conditional on valid customer coordinates.
All visual datasets remain subject to the same user, company, and warehouse
record rules as their underlying KPI and table data.

Automatic role-based access uses the standard Accounting, Sales, Inventory,
Purchase, HR and Manufacturing groups. Generated Arabic viewer/manager profiles
remain available for deliberate manual assignment per company.
